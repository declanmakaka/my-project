# Garbage Site Finder

A climate action web tool designed to help residents of Kenya find proper waste disposal methods and locate garbage collection points in their areas.

## Overview

Garbage littering is a significant environmental challenge in Kenya, affecting both urban and rural areas. This tool addresses the root cause identified by the National Environment Management Authority (NEMA): **lack of knowledge about the locations of litter bins and collection sites**.

## Features

### 1. **Waste Disposal Strategy Guide**
- Enter the type of waste you want to dispose of (Plastic, Paper, Metal, Glass, Organic, Electronics, etc.)
- Receive personalized disposal strategies and best practices
- Get multiple disposal options tailored to your waste type

**Example waste types supported:**
- Plastic
- Paper
- Metal
- Glass
- Organic
- Electronics

### 2. **Garbage Collection Point Locator**
- Select your county from all 47 Kenyan counties
- Enter your area or estate name
- Find nearby garbage collection points and disposal sites
- Get location-specific recommendations

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional installations or dependencies required

### How to Use

1. **Open the application:**
   - Open `index.html` in your web browser

2. **Find waste disposal strategy:**
   - Enter your waste type in the text input field
   - Click "Find Strategy" button
   - View personalized disposal methods and options

3. **Locate collection points:**
   - Select your county from the dropdown menu
   - Enter your area or estate
   - Click "Find Collection Points" to view nearby disposal sites
